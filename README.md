# Peter Jeong

Laboratory scientist turned healthcare data analyst, based in Seattle. Seven years of bench work in clinical and environmental microbiology, including three and a half years in a CLIA-certified public health lab reporting through the Clinisys Apollo LIS. These days I work with messy public data: I clean it in SQL, write down every row I drop and why, and end with a number a manager can act on.

**Tools:** SQL (MySQL), Tableau, Excel, Power BI

## Projects

Next up is a healthcare dataset (in progress). The Seattle project has the same shape as specimen turnaround time: median and p90 turnaround, which stage holds the slow cases, and how many correction rounds they go through.
